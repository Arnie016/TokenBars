Terminal first

Install TokenBar, claim your builder identity, then decide what to share.

The Mac app shows the live menu-bar surface. The CLI creates reports, dossiers, bundles, rankings, and optional public profile links.

pip install tokenbarInstall the CLI when the Python package is available.
curl -fsSL https://raw.githubusercontent.com/Arnie016/TokenBar/main/install.sh | bashInstall launcher and CLI.
tokenbar submit --project "My Codex App"Hackathon path: run local identity analysis, attach project metadata, publish safe proof fields, and get a TBAR token.
tokenbar proveGeneric proof path: run local identity analysis, publish only safe proof fields, and get a TBAR token.
tokenbar proof latestRecover the last safe proof token, public links, privacy receipt, and share copy without rerunning analysis.
tokenbar videoGenerate a privacy-safe HyperFrames-ready shot list for a 30-second TokenBar product video.
tokenbar claimGenerate a private local identity packet, Skill.md, and report without publishing.
tokenbar save https://example.com --tag agent-loopSave a social/GitHub/blog reference to your local builder-signal inbox. Nothing is uploaded.
tokenbar inbox digestReview saved builder signals by host and tag before using them in a report or proof story.
tokenbar publish-proofOpt in to a safe proof-card run, profile link, feed entry, and rankings evidence.
tokenbar identityGenerate the default local builder profile without publishing.
tokenbar profile --pdfCreate a print-ready PDF report.
tokenbar submit --project "My Codex App" --repo https://github.com/me/app --demo https://app.example.comSubmit a repo with public project links; raw repo contents still stay local.
tokenbar socialOpen the public profile and leaderboard layer.
tokenbar rankingsShow local identity leaderboard from your snapshots.
tokenbar bundlePackage report, Skill.md, JSON, and proof manifest.

Run locally

TokenBar reads Codex first, then Claude Code, Cursor, and Gemini connectors as they are enabled. Raw transcripts stay on your machine.

Publish safely

tokenbar submit is the hackathon/social path. tokenbar prove is identity-only proof. Both run locally first, then upload only generated safe proof fields. Use tokenbar claim when you want a private review before any public token exists.

Report corrections

Reports include a feedback endpoint for disputes, misclassification, or takedown requests. AgentMail delivery is enabled when the deployment has feedback env vars configured.
