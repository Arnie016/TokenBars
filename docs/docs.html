Local bridge

One safe bundle for the app, CLI, and Codex.

tokenbar api serves generated Builder Identity fields and aggregate usage on localhost. tokenbar mcp exposes that same read-only contract to Codex over stdio. Neither is a raw-log endpoint.

codex mcp add tokenbar -- tokenbar mcpConnect the installed TokenBar CLI to Codex. Codex receives three read-only tools: Builder Identity, aggregate usage, and the combined safe bundle.
tokenbar mcpRun TokenBar's newline-delimited JSON-RPC stdio server directly. Stdout contains MCP messages only; nothing is uploaded.
tokenbar apiStart the read-only local API at 127.0.0.1:8769. It refuses remote binding by default.
curl http://127.0.0.1:8769/v1/bundleRead the combined identity and usage bundle. Other resources are /v1/identity, /v1/stats, and /health.
tokenbar api --snapshot --output tokenbar-safe-bundle.jsonPackage the same privacy-safe contract as a portable JSON file without starting a server.

Connect Codex

In Builder Story, press Connect Codex to copy a command using the CLI bundled inside that exact app. Paste it in Terminal once; remove it later with codex mcp remove tokenbar.

Run locally

TokenBar reads Codex first, then Claude Code, Cursor, Antigravity, and OpenCode connectors as they are enabled. Raw transcripts stay on your machine.

Publish safely

tokenbar submit is the hackathon/social path. tokenbar prove is identity-only proof. Both run locally first, then upload only generated safe proof fields. Use tokenbar claim when you want a private review before any public token exists.

Add spotlight context

Use tokenbar claim SESSION_ID for the simple path. Add --spotlight-project, --spotlight-struggle, --spotlight-feature, and --spotlight-progress only when you want to label the story more precisely without uploading the transcript.

Report corrections

Reports include a feedback endpoint for disputes, misclassification, or takedown requests. AgentMail delivery is enabled when the deployment has feedback env vars configured.
