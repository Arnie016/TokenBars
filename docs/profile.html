Each builder gets a shareable profile, not just a repo link.

Run TokenBar from the project you are submitting. The command turns local Codex and agent evidence into a private identity artifact, attaches your public repo/demo links, then publishes a safe proof token when you are ready.

Judge flow

Local evidence to public story, without turning into surveillance.

The product is not a GitHub clone or a vanity token scoreboard. It is a compact identity narrative backed by safe aggregate evidence and visible uncertainty.

  1. 01Local Codex evidence

    Usage totals, bounded/redacted session signals, action stages, and report metadata stay under the builder's control.

  2. 02Server-side action

    The proof action persists request, stages, proof card, profile link, social feed entry, and ranking evidence.

  3. 03Selective profile

    Public, selective, and private modes make it clear which claims are shareable and which are self-review only.

  4. 04Reloadable proof

    A TBAR-... token lets someone reopen the same safe proof without seeing raw workspace data.
