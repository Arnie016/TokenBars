# TokenBar Builder Identity Trailer Brief

This is the default production brief for a 30-second TokenBar Builder Identity trailer. It is designed for HyperFrames, Director Bay, Remotion, or any HTML/CSS/JS video renderer.

## Creative Position

TokenBar is a local-first Builder Identity app for Codex, Claude Code, Gemini, Cursor, and other agent workflows. The video should make the viewer feel: "My AI work has evidence, rhythm, taste, and a public proof layer."

Style: premium product film, dark glass app surface, white editorial report paper, subtle grain, thin measurement lines, archetype-driven accent color, no generic SaaS blobs.

Core analogy: scattered AI work becomes a passport dossier. The first three seconds should show fragments becoming a proof object before the app UI appears.

## Privacy Boundary

Show only:

- Aggregate usage counts
- Safe identity labels
- Proof/loop/specificity scores
- TBAR token format
- Public profile/feed/ranking surfaces

Never show:

- Raw transcripts
- Private prompts
- Source code
- Credentials or environment variables
- Private diffs
- Unredacted repo paths

## 30-Second Micro-Storyboard

1. `0-3s` Scattered work becomes a dossier
   Floating fragments labelled Codex, Claude Code, Gemini, and Cursor collapse into one clean identity passport. One-word card: `SEEN`.

2. `3-8s` Live menu-bar proof
   The macOS menu-bar surface opens. Forecast, provider tabs, cost, selected day marker, and quick insights are readable.

3. `8-13s` Run the claim
   Terminal runs `tokenbar prove`; six stages light up: scan, analyze, score, redact, sign, publish. End on a TBAR token and privacy receipt.

4. `13-18s` Builder identity reveal
   A passport card resolves into the latest builder title. Proof and loop scores are labelled as evidence-backed confidence, not vanity ranks.

5. `18-23s` Proof card and social layer
   A public proof card opens beside a For You feed of shipped work and self-over-time rankings.

6. `23-27s` Local-first boundary
   Split screen: local machine holds raw sessions; public profile receives only generated safe fields.

7. `27-30s` One command
   Download for macOS. Run `tokenbar prove`. Paste the TBAR token. Own your builder identity.

## Voice Timing Contract

- `0-3s`: Your AI work has a shape, even before your resume can explain it.
- `3-8s`: TokenBar reads the local trail: tokens, sessions, pace, and pressure.
- `8-16s`: Run one command. It scans locally, scores the pattern, redacts the private parts, and signs a proof token.
- `16-23s`: This becomes a builder passport with evidence people can inspect.
- `23-30s`: Share the proof. Keep the raw work. Build the identity graph for how AI builders actually build.

- Command-palette edits should target stable manifest fields.
- Keyframes should be editable, not buried in renderer code.
- Voice windows should follow `0-3 / 3-8 / 8-16 / 16-23 / 23-30`.

- A validator should reject fake proof, unreadable timing, and privacy leaks.


## Capture Checklist

- `tokenbar usage` terminal close-up with the large 7d token line
- macOS TokenBar overview, forecast, quick insights, and provider tabs
- `tokenbar prove` output showing safe stage names and generated token
- `/profile?token=TBAR-...`
- `/social?token=TBAR-...`
- `/rankings?token=TBAR-...`
- One report/PDF page with a white premium editorial background and provenance footer

## Anti-Slop Gate

- Do not make a slideshow.
- Do not hide the product until the ending.
- Do not use more than one CTA.
- Do not animate cursor movement unless the click produces a visible UI state change and proof reveal.
- Do not use private text, raw prompts, unredacted paths, source code, or credentials as trailer texture.
