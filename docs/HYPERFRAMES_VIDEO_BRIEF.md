# TokenBar HyperFrames Video Brief

This is the default production brief for a 30-second TokenBar demo video. It is designed for HyperFrames or any HTML/CSS/JS video renderer.

## Creative Position

TokenBar is a local-first Builder Identity app for Codex, Claude Code, Gemini, Cursor, and other agent workflows. The video should make the viewer feel: "My AI work has evidence, rhythm, taste, and a public proof layer."

Style: premium product film, dark glass app surface, white editorial report paper, subtle grain, thin measurement lines, archetype-driven accent color, no generic SaaS blobs.

## Privacy Boundary

Show only:

- Aggregate usage counts
- Safe identity labels
- Proof/loop/specificity scores
- TBAR token format
- Public profile/feed/ranking surfaces

Never show:

- Raw transcripts
- Private prompts
- Source code
- Credentials or environment variables
- Private diffs
- Unredacted repo paths

## 30-Second Shot List

1. `0-4s` Menu-bar cold open
   A tiny macOS status item expands into the TokenBar control surface. Show token count, forecast line, and provider tabs.

2. `4-8s` CLI proof run
   Terminal runs `tokenbar prove`. Six stages light up: scan, analyze, score, redact, sign, publish. End on a TBAR token.

3. `8-13s` Identity reveal
   A report card resolves into a builder title. Scores animate as evidence-backed dimensions, not vanity badges.

4. `13-18s` Proof passport
   A share card shows proof score, loop maturity, sessions, aggregate tokens, and the redaction boundary.

5. `18-23s` Social layer
   Show the For You shipped-work feed, then rankings by proof, loop maturity, specificity, region, and self-over-time improvement.

6. `23-27s` Privacy split
   Local machine holds raw logs. Public web receives only generated safe proof fields.

7. `27-30s` CTA
   Download for macOS. Run `tokenbar prove`. Paste the TBAR token. Own your builder identity.
