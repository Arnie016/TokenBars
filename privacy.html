TokenBar Mobile Privacy

TokenBar Mobile is designed to show aggregate coding-agent usage without copying the private work behind it.

Data processed on your devices

When you choose to connect a Mac, TokenBar transfers an aggregate analytics record over your local network using a short-lived, one-use code. The record can include token totals, dates, model and provider labels, cost assumptions, forecast ranges, and derived working-pattern summaries.

Data excluded from the handoff

TokenBar does not include raw prompts, chat transcripts, source code, secrets, credentials, or private file paths in the mobile analytics handoff.

Storage and deletion

The imported aggregate is stored on the phone. You can remove it from Settings by choosing Forget imported record. That action does not delete the original local logs on the Mac.

Network access

Pairing uses HTTP on your local network. The one-use code limits access but does not encrypt the transfer. Connect only on a network you trust, or import an exported file instead.

The app retrieves public model rankings from Hugging Face and public reset information from codex-resets.com. These requests include the network information needed to deliver a response, such as your IP address, but do not include your imported token record or private notes. Those services apply their own privacy terms.

Research, product, and course links open when you select them. The linked sites apply their own privacy terms. The course link includes a referral code.

Sharing

TokenBar does not publish your imported record automatically. Any future social sharing must be an explicit user action and should contain only the fields shown in its preview.

Estimates

Cost and forecast figures are analytical estimates. They are not provider invoices and are not used for automated financial decisions.

Contact

General questions can be submitted through the TokenBar issue tracker. Issues are public: do not include private logs, pairing codes, credentials, or personal information.
